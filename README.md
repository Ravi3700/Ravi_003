# Professional Data Analyst Portfolio

**Created & Developed by Ravi Kumar Shrivastav**  
*Business Intelligence • Power BI • SQL • DAX • Data Modeling • ETL Workflows*

---

## 🌟 Overview

This is the official portfolio web application created and maintained by **Ravi Kumar Shrivastav**, showcasing end-to-end Data Analytics capabilities:
* **Interactive Power BI Dashboards & Case Studies**: End-to-end business intelligence reports covering Sales Analytics, HR Workforce, Financial Variance, and Customer Retention.
* **Smart Floating Contact Hub**: A draggable, compact floating action launcher providing 1-click access to WhatsApp and DataMate AI.
* **DataMate AI Assistant**: A grounded AI portfolio assistant powered by Google Gemini and grounded in verified portfolio and resume knowledge.
* **Theme Studio**: Custom multi-theme visual engine (Slate Pro, Corporate Blue, Emerald Analytics, Midnight Carbon, Sunset Amber, Rose Gold).
* **Live Visitor Counter**: Real-time unique visitor and session tracking powered by Firebase Firestore.

---

## 💻 Tech Stack & Dependencies

* **Frontend Framework**: React 19 + TypeScript
* **Build Tooling & Server**: Vite + Node.js Express + TSX / esbuild
* **Styling**: Tailwind CSS v4 + Motion
* **Iconography**: Lucide React
* **Backend Intelligence**: Google GenAI SDK (`@google/genai`)
* **Cloud Database & Analytics**: Firebase Firestore
